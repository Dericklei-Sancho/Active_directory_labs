Active Directory Home Lab
Overview
This project demonstrates the deployment and administration of a Windows Server 2025 Active Directory environment using Oracle VirtualBox.

The lab simulates a small business environment named "DerickLab" and includes a Domain Controller, Active Directory Domain Services (AD DS), DNS, Organizational Units, users, security groups, folder permissions, Group Policy Objects (GPOs), and a Windows 11 client machine joined to the domain.

The purpose of this project was to gain hands-on experience with Windows Server administration, user management, domain authentication, troubleshooting, and enterprise IT infrastructure.
